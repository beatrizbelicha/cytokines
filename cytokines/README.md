# Gastric Cancer Cytokine Profiling & Statistical Analysis

## Overview
This repository contains the bioinformatics and statistical pipeline for analyzing multiplexed cytokine, chemokine, and growth factor data obtained via the **MAGPIX system (Luminex xMAP technology)**. The primary focus of this project is to evaluate the immune landscape and the tumor microenvironment (TME) in patients with **gastric cancer**.

## Scientific Context
In gastric cancer, the tumor microenvironment is shaped by complex paracrine signaling networks. By quantifying soluble immunological mediators (such as interleukins, TNF, IFNs, and growth factors), this project aims to identify distinct inflammatory and immunosuppressive profiles that may correlate with clinical phenotypes and disease progression.
