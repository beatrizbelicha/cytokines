2.2 Define the metadata column that separates groups

Here we are assigns the string “condicao” (the name of our clinical metadata column) to the variable condition. This parameterizes the script. By assigning the grouping variable (e.g., controle x câncer) to an object, avoid hardcoding the column name throughout the pipeline. 2.3 Identify cytokines columns

colnames() extracts all column names, and ncol() counts the total number of columns. The 12:ncol() indexing subsets the vector of names, selecting only those from the 12th column to the last. Early columns contain categorical metadata, we assume the actual biomarker concentrations begin at column 12. Isolating these names into cytokines_names allows us to apply mathematical transformations exclusively to analytical variables, preventing execution errors on demographic columns.

cytokine_names <- colnames(data.cytokines)[12:ncol(data.cytokines)]

list() initializes empty list objects, which act as structured storage containers. To handle multiplexed data iteratively (via loops) without polluting the Global Environment. These lists act as clean folders to store individual cytokine dataframe (df_list) and their corresponding plots (plot_list) systematically during the loop execution.

df_list <- list()
plot_list <- list()

2.5 Correcting from , to .

MAGPIX software often exports numerical data with commas (e.g., 140,5) and out-of-range string (e.g., “OOR<”). R interprets these columns as discrete characters. This specific combination rectifies the decimal formatting (140.5) and forces non-numerical strings into NA. This is an absolute prerequisite for rendering continuous plots and running non-parametric statistical test correctly.

The pipe |> forwards the raw data to mutate, which modifies columns. The acroos function applies a rule simultaneously to all columns specified in cytokine_names. The rule uses gsubs(",", ".", .) to find commas and replace them with dots, followed by as.numeric to coerce the result into a continuous numeric format.

data.cytokines <- data.cytokines %>%
  mutate(across(all_of(cytokine_names), ~ as.numeric(gsub(",", ".", .))))

2.6 Loop through each cytokine to subset data and generate plot

Part 1: The for (cyt in cytokine_names) statement initializes a loop. It instructs R to take the first cytokine name from the list, assign it to the placeholder cyt, and run the code block; then repeat for the next name, until the list ends.

  • Inside the loop, a temporary dataframe named df_temp is created. The pipe (%>%) takes the main dataset (data.cytokines) and uses the selectfunction to subset only two columns: the clinical group column (condition) and the current cytokine column (cyt).
  • Finnaly, the drop_na function scans this two-column dataframe and removes any row (patient) containing a missing value (NA).

Part 2: This line takes the newly cleaned, two-column temporary dataframe (df_temp) and stores it inside the previously initialized list (df_list). The double bracket indexing [[cyt]] dynamically names this specific element/slot in the list using the current cytokine’s string name (e.g., IL_6).

A loop is iterative. Without this lines of code, the df_temp object would be overwritten in the very next cycle, and the previous cytokine’s cleaned data would be permanently lost. By storing each df_temp into df_list, we ensure that after the loop finishes, all subsetted and cleaned datasets are preserved and neatly organized in your RAM. If, after generating the plots, we decide to run a Shapiro-Wilk normality test exclusively on a specific cytokine, we don’t need to subset the data again, we simply call df_list[["Cytokine"]]` to retrieve the exact dataset.

Part 3: In tumor immunology, before computing any p-value, we must visually assess the data distribution. Cytokine-driven immune responses rely on positive feedback amplification loops. Consequently, the data rarely follows a perfect “bell curve” (Gaussian distribution). Instead, the cancer group will likely exhibit a long right-tail, reflecting biological outliers (patients with a hyper-inflamed tumor microenvironment). The transparency (alpha) and non-stacked overlapping (identity) arguments are crucial here: they allow you to see the exact translucent intersection between the basal immune tone of the control group and the pathological profile of the Gastric Cancer cohort on the same visual plane.

  • p_hist <- ggplot(): initializes the plot canvas and assigns is to the object p_hist.
  • aes(...): The aes (aesthetics) function maps the visual properties. The X-axis represents the cytokine concentration. The .data[] syntax is an advanced tidyverse pronoun used inside loops to dynamically evaluate the string variable as a column name. The fill argument colors the bars according to the patient’s clinical group.
  • geom_histogram(...): instructs ggplot to render frequency bars. alpha = 0.6 adds transparency. position = "identity" forces the bars to overlap on the same baseline rather than stacking on top of each other. bins = 30 divides the data range into 30 intervals. And color = "black" adds borders to the bars.
  • theme_minimal(): strips away the default gray background, applying a clean.
  • labs(...): uses the paste() function to concatenate strings dynamically (e.g., “Distribuição da” + “IL_6”), generating the title, subtitle and axis labels.
  • scale_fill_manual(...): overrides default palettes with specific hexadecimal colors.

Part 4: In the tumor immunology, multiplexed cytokine profiles are not notoriously non-parametric. Relying on the statistical “mean” is critically flawed because it is heavily skewed by hyper-inflamed patients. The boxplot is mandatory here because it centers on the median, a robust metric resistant to extremes. Furthermore, highlighting the outliers in pink is not merely aesthetic. In clinical bioinformatics, these biological outliers are rarely technical MAGPIX errors, they often represent hyper-responsive patients. Highlighting the visually aids in generating vital biological and clinical hypotheses.

  • p_bpx <- ggplot(...): initializes the plot, Unlike histogram, the mapping shifts: the X-axis receives the categorical variable, and the Y-axis maps the continuous variable. fill colors the boxes based on the group.
  • geom_boxplot(...): renders the box-and-whisker plot. Unlike a standard bar chart that displays the mean, the boxplot visually represents the Median (the thick horizontal line inside the box) and the Interquartile Range (IQR) (the boundaries of the box, containing the middle 50% of our cohort).
  • The outlier arguments (outlier.color = "pink", outlier.shape = 16, outlier.size = 2): instruct R to identify data points that fall statistically outside the whiskers and render them a solid dots (shape = 16), sized at 2, and colored pink.
  • scale_fill_manual(...): applies our updated custom hexadecimal color palette.
  • theme(...): a publication-quality design tweak. Since the X-axis is already explicitly labeled with the group names, a side legend mapping colors to group is redundant. This command removes the legend, maximizing plotting area.

Part 5: The inherent behavior of a loop is to overwrite its internal placeholder variables. When the IL-6 iteration finishes and loop moves to IL-10, the previous p_hist and p_box objects are overwritten and lost. Without storing them in a list, once the loop finishes iterating over all our cytokines, we would only have access to the plot of the very last molecule in the array. By employing this dynamic storage strategy, we compile a comprehensive, easily accessible graphic library within our R environment. If our PI later requests a high-resolution export of a specific mediator, we won’t need to rerun the pipeline, executing `plot_list[[“cytokine_box”]] will instantly retrieve and render that specific figure.

  • The paste0() function concatenates string without inserting whitespace. It takes the variable cyt and merges it with the "_hist" or "_box" suffices, generating a unique identifier string, such as "IL_6_hist".
  • The double brackets [[]] use this generated string to name a specific slot within our previously initializes plot_list.
  • The assignment operator <- the stores the fully rendered ggplot objects (p_hist and p_box) into these precisely named slots.

Part 6: The print() function explicitly commands R to display the p_hist and p_box graphical objects visually on our screen. If we execute the name of a ggplot object (like p_hist) directly in the console, it renders automatically. However, inside a loop, R defaults to a “silent mode” to optimize processing speed. It evaluates the plot and stores in the memory (in our list), but it suppresses visual output. Without explicitly wrapping the plot objects in the print() function, our script would run flawlessly, but our final document would be completely blank. This command forces the rendering engine to actively draw and embed each histogram and boxplot into our report dynamically as the loop iterates.

for (cyt in cytokine_names) {
  #--Subsetting data--
  #Create a specific dataframe for the current cytokine, dropping missing values (NA)
  df_temp <- data.cytokines %>%
    select(all_of(condition), all_of(cyt))%>%
    drop_na()

  #Store the specific cytokine dataframe into out list
  df_list[[cyt]] <- df_temp

  #--Histogram Plot--
  #Evaluates the data distribution
  p_hist <- ggplot(df_temp, aes(x = .data[[cyt]], fill = .data[[condition]])) +
    geom_histogram(alpha = 0.6, position = "identity", bins = 30, color = "black") +
    theme_minimal()+
    labs(
      title = paste("Distribuição da", cyt),
      subtitle = "Histograma para avaliação da distribuição",
      x = "Concentração (pg/mL)",
      y = "Frequência"
    ) +
    scale_fill_manual(values = c("#e34230ff", "#345edbff")) #Blue for control, Red for cancer

  #--Boxplot--
  #Evaluates medians, interquartile ranges, and biological outliers
  p_box <- ggplot(df_temp, aes(x = .data[[condition]], y = .data[[cyt]], fill = .data[[condition]])) +
    geom_boxplot(alpha = 0.7, outlier.color = "pink", outlier.shape = 16, outlier.size = 2) +
    theme_minimal() +
    labs(
      title = paste("Nível de", cyt, "por grupo"),
      x = "Grupo Clínico",
      y = "Concentração (pg/mL)"
    ) +
    scale_fill_manual(values = c("#e34230ff", "#345edbff")) +
    theme(legend.position = "none") #Hides legend since x-axis already has the group names

  #Store plots in the list
  plot_list[[paste0(cyt, "_hist")]] <- p_hist
  plot_list[[paste0(cyt, "_box")]] <- p_box

  #Render plots in the document
  print(p_hist)
  print(p_box)

}

3 Testing the normality of each cytokine.

3.1 Initialize an empty dataframe to store the final results

normality_results <- data.frame(
  Citocina = character(),
  Condição = character(),
  p_valor = numeric(),
  Distribuição = character(),
  stringsAsFactors = FALSE
)

3.2 Create the loop

Here we need to separate, because testing distinct immunological states within the same sample triggers the bimodal distribution trap, yielding false negatives. The control group and the cancer group do not belong the same biological population.

Part 1: The filter() function acts as a strict subsetting funnel. It scans the rows of our df_temp and creates df_controlcontaining only the patients where the condition column matches “controle”. It repeats this logic for the “cancer” cohort. The filter function guarantees biological isolation prior to testing. Furthermore, R’s native Shapiro-Wilk function strictly requires a continuous numeric vector as its input, not a multi-variable dataframe. - The [[cyt]] indexing extracts the specific cytokine column from the dataframe and coerces it into a pure numeric vector (a simple array of numbers).

Parte 2: In the Shapiro-Wilk framework, the Null Hipothesis (H0) assumes the data is normally distributed. Statistically, a p-value < 0.05 rejects this normality. Automating this logical step with ifelse() eliminates the need for manual interpretation of dozens of p-values, effectively neutralizing the risk of human error in our data pipeline. The script makes the statistical triage.

  • The shapiro.teste() function computes the Shapiro-Wilk mathematical algorithm on our numeric vector.
  • The $p.value suffix acts as a data extractor: the test outputs a larger list of statistics, but we command R to surgically extract only the p-value, storing it in p.value_control ou p.value_cancer. -The ifelse(condition, true, false) function is a logical decision engine. It evaluates the p-value threshold. If p > 0.05, it outputs the string "Normal". If not, it outputs "Não Normal".

Part 3: We create a two-row temporary table (temp_results) containing the cytokine name, the group, the p-value, and the distribution status. Finally, bind-rowsfunction “pastes” these two rows at the bottom of our main table (normality_results).

for (cyt in cytokine_names) {
  # Retrive the cleaned dataframe for the current cytokine from our list
  df_temp <- df_list[[cyt]]

  #--Separating the groups--
  #Filter data by clinical group
  df_control <- df_temp |> filter(.data[[condition]] == "controle")
  df_cancer <- df_temp |> filter(.data[[condition]] == "cancer")

  #Extract purely the numeric vectors for the test
  vec_control <- df_control[[cyt]]
  vec_cancer <- df_cancer[[cyt]]

  #--Shapiro-Wilk Normality Test
  #Run the test and extract only p-value
  p.value_control <- shapiro.test(vec_control)$p.value
  p.value_cancer <- shapiro.test(vec_cancer)$p.value

  #Determine distribution based on the p-value threshold (Alpha = 0.05)
  dist_control <- ifelse(p.value_control > 0.05, "Normal", "Não Normal")
  dist_cancer <- ifelse(p.value_cancer > 0.05, "Normal", "Não Normal")

  #--Consolidating the results--
  temp_results <- data.frame(
    Citocina = c(cyt, cyt), 
    Condição = c("Controle", "Câncer"), 
    p_valor = c(p.value_control, p.value_cancer),
    Distribuição = c(dist_control, dist_cancer), 
    stringsAsFactors = FALSE
  )

  #Append these results to our main general dataframe
  normality_results <- bind_rows(normality_results, temp_results)
}

4 Appling the transformation

Cytokine data commonly follows a right-skewed distribution, with most values clustered at the lower end and a few extreme high values. This violates the normality assumptions required by many parametric statistical tests.

4.1 Log

The transformation in one the most widely used strategies to address the problem of normality, as it compresses the scale of high values and pulls the distribution closer to a normal curve. However. it’s essential to verify whether the transformation was actually effective by comparing the data distribution before and after, for example, using plots or normality test. Applying a transformation without testing it can create a false sense that the assumptions have been met, ultimately compromising the validity of downstream analyses.

This code create a new datarame called data.log from data.cytokines, applying a natural logarithm transformation to all cytokine columns. The pipe operator (|>) passes data.cytokines as the first argument to the next function. The mutate() function, from the dplyr package, modifies or create columns in a dataframe, in this case, it overwrites the selected cytokines columns with their log-transformed values.

The across() function applies a transformation to multiple columns simultaneously, avoiding repetitive column-by-column operations. It takes two arguments:

  1. all_of(cytokines_names), which selects only the columns listed in the cytokines_names vector and raises an error if any name is missing from the dataframe;

  2. ~log(.), an anonymous function where ~ defines the formula and . refers each column being processed, computing the natural logarithm (base e) of every value.

data.log <- data.cytokines |> 
  mutate(across(all_of(cytokine_names), ~ log(.)))

This code creates an empty dataframe called normality_log, which servers as a structured container to store the results of normality tests applied to the transformed data. Each arguments defines a column with it corresponding data type:

  • Transformação = character() and Citocinas = character() store, respectively, the name of the transformation applied and the name of cytokine tested. Condição = character() identifies the experimental group. p_valor = numeric() holds the p-value returned by the test. Distribuição = character() records the conclusion about the data distribution. Finally, stringsAsFactor = FALSE instructs R to keep text columns as character type, preventing them from being automatically converted to factor, which could cause issues when appending new rows to the dataframe.
normality_log <- data.frame(
  Transformação = character(),
  Citocina = character(),
  Condição = character(),
  p_valor = numeric(),
  Distribuição = character(),
  stringsAsFactors = FALSE
)
for (cyt in cytokine_names) {

  df_temp <- data.log %>%
    select(all_of(condition), all_of(cyt)) %>%
    drop_na()

  vec_control <- df_temp %>%
    filter(.data[[condition]] == "controle") %>%
    pull(all_of(cyt))

  vec_cancer <- df_temp %>%
    filter(.data[[condition]] == "cancer") %>%
    pull(all_of(cyt))

  p.value_control <- shapiro.test(vec_control)$p.value
  p.value_cancer <- shapiro.test(vec_cancer)$p.value

  dist_control <- ifelse(p.value_control > 0.05, "Normal", "Não Normal")
  dist_cancer <- ifelse(p.value_cancer > 0.05, "Normal", "Não Normal")

  temp_results <- data.frame(
    Transformação = "Log",
    Citocina = c(cyt, cyt),
    Condição = c("Controle", "Câncer"),
    p_valor = c(p.value_control, p.value_cancer),
    Distribuição = c(dist_control, dist_cancer),
    stringsAsFactors = FALSE
  )

  normality_log <- bind_rows(normality_log, temp_results)
}

4.2 Log1p

The log() function computes the pure natural logarithm, if any value in the data is zero, the result will be -Inf, which breaks downstream analyses. The log1p() function, on the other hand, computes log(1 + x), adding 1 to each value before applying the logarithm. This ensures that zeros are transformed to log(1) = 0, avoiding the problem entirely. For cytokines data, where zero values are biologically plausible, log1p() is generally the safer choice.

data.log1p <- data.cytokines |> 
  mutate(across(all_of(cytokine_names), ~ log1p(.)))

5 PCA

5.1 Raw data

This code creates a matrix called pca.raw.matrix by selecting only the cytokines columns from the dataframe data.cytokines. The dplyr::select() function is called with explicit package notation to make clear which package it comes from and to avoid conflicts with functions of the same name loaded from other packages in the session. The result is a dataframe containing only the raw, untransformed cytokines values, which will be used as input for the Principal Component Analysis (PCA).

The prcomp() function runs a PCA on the raw cytokines data and stores the results in the object pca.raw. The function is R’s built-in PCA implementation and takes the following arguments:

  • pca.raw.matrix: is the dataframe containing only the raw cytokine values, prepared in the previous step;

  • center = TRUE: centers the data by subtracting the mean of each variable, so that all columns have a mean of zero, this is essential to prevent variables with very different means from dominating the principal components;

  • scale. = TRUE: scales the data by dividing by the standard deviation of each variable, giving all of them a variance pf 1. This is particularly important when cytokines are measured on different scales or units, preventing those with numerically larger values from having a disproportionate influence on the analysis. The dot in the argument name is a quirk of the function designed to avoid conflict with R’s base scale() function.

We now prepare the PCA results for visualization by organizing them into a dataframe and extracting the variance explained by each component.

pca.raw$x accesses the scores matrix from the prcomp() output, which contains the coordinates of each sample in the new dimensional space defined by the principal components. The as.data.frame() function converts this matrix into a dataframe, a more convenient format for plotting. A new column called condicao is then added to the dataframe. The pull() function from dplyr extracts a single column from a dataframe as a plain vector — in this case, the column whose name is stored in the variable condition. This allows each point in the PCA plot to be colored or grouped according to the experimental condition of each sample. Finally, summary(pca.raw)$importance returns a matrix of metrics for each principal component, where row [2,] corresponds to the proportion of variance explained. The [1:2] index selects only the first two components (PC1 and PC2), which are the ones that will be plotted. The result is multiplied by 100 to convert to a percentage and rounded to one decimal place using round(..., 1).

Finally, the PCA is plotted using ggplot2. The pca.raw.df dataframe is passed as the base data, and within aes() the aesthetic mappings are defined: x = PC1 and y = PC2 position each sample on the cartesian plane according to its coordinates in the first two principal components, while color = condicao colors each point according to the experimental group of that sample.

  • geom_point(size = 3) adds the points to the plot, with size 3 for better visibility.

  • labs() defines the plot’s text elements, title names the plot, and the x and y arguments dynamically build the axis labels using paste0(), which concatenates the component name with its explained variance from the var.raw vector, producing labels such as “PC1 (32.5%)”.

  • theme_minimal() applies a clean visual theme that removes unnecessary graphical elements, making the plot more elegant and easier to interpret.

This block runs the Mann-Whitney test for each cytokine individually and stores the results in a dataframe. The for(cyt in cytokine_names) loop iterates over each cytokine name in the cytokine_names vector, with cyt taking a different cytokine name at each iteration. Inside the loop, as.formula(paste(cyt, "~", condition)) dynamically builds the statistical formula by concatenating the cytokine name, the tilde ~, and the condition name into a string such as "IL6 ~ group", then converting it into a formula object that R can interpret statistically.

wilcox.test() runs the Mann-Whitney test (also known as the Wilcox rank-sum test) comparing cytokine values between the groups defined by condition variable. It is a non-parametric test, appropriate for data that does not follow normal distribution.

At each iteration, a temporary dataframe temp is created with three columns:

  1. The cytokine name;

  2. The p-value;

  3. Classification using ifelse().

The ifelse() function returns “Significativo” if the p-value is less than or equal to 0.05 and “Não Significativo” otherwise. The bind_rows() function from dplyr the appends temp to the main results results.mann.raw dataframe, accumulating results across iterations.

After the loop, print() displays the complete results dataframe, and table() produces a quick count of how many cytokines were classified as significant or non-significant.

for(cyt in cytokine_names){

This code generates the heatmap using pheatmap() function from the package of the same name. each argument controls a specific aspect of the visualization:

  • t(heatmap.matrix) transpose the matrix, swapping rows and columns so that cytokines appear as rows and samples as columns, which is the most common and intuitive orientation for biological heatmaps. scale = "row" normalizes the data by row, transforming the values of each cytokine into z-scores by subtracting the mean and dividing by the standard deviation. This allows the expression pattern of cytokines with very different magnitudes to be compared without one visually dominating the others.

  • annotation_col = annotation.df adds an annotation bar at the top of the columns, coloring each sample according to its experimental group using the annotation dataframe created earlier. annotation_colors = annotation_colors assigns the specific colors for each group in that annotation bar, using the color list defined previously.

  • clustering_method = "complete" sets the hierarchical clustering method used to order both samples and cytokines in the heatmap. The "complete" method calculates the distance between two clusters as the greatest distance between any two points belonging to them, tending to produce more compact and well-defined clusters. border_color = "#fcfcfc" sets the border color between heatmap cells to a near-white tone, creating a subtle separation without distracting from the visualization. Finally, fontsize = 10 sets the font size of the labels in the plot.

pheatmap(
  t(heatmap.matrix),
  scale = "row",
  annotation_col = annotation.df,
  annotation_colors = annotation_colors,
  clustering_method = "complete", 
  border_color = "#fcfcfc",
  fontsize = 10
)
